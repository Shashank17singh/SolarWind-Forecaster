ML Models
🌪️ Storm_Risk_Model
PK model_id: storm_lgbm
• algo: LightGBM Classifier
• target: P(SYM/H ≤ -50 nT)
• horizon: +15 minutes
• features: 220
• calibrator: Isotonic Regression
• output: probability 0–1
• file: storm_model.joblib
📉 SYM/H_Regression
PK model_id: symh_lgbm
• algo: LightGBM Regressor
• target: SYM/H at +15 min (nT)
• features: 220
• metric: MAE, RMSE
• output: float (nanoTesla)
• file: symh_model.joblib
🧠 Dst_LSTM_Attention
PK model_id: dst_lstm
• algo: BiLSTM + Attention (Keras)
• Layer1: BiLSTM(150) → Attention
• Layer2: BiLSTM(170) → Attention
• target: Dst at +1h, 72h series
• seq_len: 48 hours
• features: 49
• file: dst_lstm_attention.keras
🔥 Flare_Risk_Model
PK model_id: flare_lgbm
• algo: LightGBM Classifier
• target: P(M/X flare in 15 min)
• fallback: GOES X-ray flux proxy
• calibrator: Isotonic Regression
• output: probability + class label
• file: flare_model.joblib
🛸 Drag_DTC_Model
PK model_id: drag_lgbm
• algo: LightGBM Regressor
• target: JB2008 DTC at +3 hours
• output: DTC → drag acceleration
• F = 0.5×Cd×A×ρ×v²
• file: drag_model.joblib
⚠️ Sat_Impact_Model
PK model_id: sat_impact
• algo: LightGBM Classifier
• target: P(anomaly in 6h)
• trained on: NCEI anomaly records
• output: prob + Low/Elevated/High
• file: sat_impact_model.joblib
💥 CME_Impact_Model
PK model_id: cme_impact
• algo: LightGBM (2 models)
• Model 1: impact probability
• Model 2: transit time (hours)
• input: speed, width, lat, lon, halo
• file: cme_impact_model.txt

API Server
🖥️ API_Server
PK server: src/server.py
• ThreadingHTTPServer (Python)
• Port: 8000
• Rate limit: 5 req/sec, burst 20
• API Key auth (optional)
• Cache TTL: 30 seconds
• Rotating logs (2MB × 3)

Infrastructure

• Base: python:3.12-slim
• Mounts: data/, models_deploy/
• Env: API_KEY, DATA_DIR, MODEL_DIR

• Deployment: api-server pod
• Service: ClusterIP / LoadBalancer
• HPA: auto-scale on CPU/mem
• Rolling updates (zero downtime)
• Health: /api/health liveness probe
